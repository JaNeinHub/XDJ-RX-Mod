3 Build

    4 Your files

    Each file is called XDJRX.UPD, because that's the only name the XDJ-RX looks for. Put one at a time on an empty USB stick, at the top level.

    The stick: FAT32 and MBR

    The stick must be formatted FAT32 (MS-DOS FAT) with the partition scheme Master Boot Record (MBR). A FAT32 stick with a GPT partition table is not recognised by the update mode.

    Mac: Disk Utility → View → Show All Devices → select the stick itself (the top entry, not the volume below it) → Erase → Format "MS-DOS (FAT)", Scheme "Master Boot Record".
    Windows: most sticks already are MBR. To check: right-click Start → Disk Management → right-click the stick's disk (on the left) → Properties → Volumes → "Partition style". If it says GPT: right-click the stick's volume → Delete Volume (this erases the stick; make sure it's the stick), then right-click its disk → Convert to MBR Disk, then right-click the empty space → New Simple Volume → FAT32. (Windows makes FAT32 volumes only up to 32 GB; on a bigger stick, a 32 GB volume is fine.)

    Emergency file R2 read first

    Pioneer's complete official firmware 2.21, unchanged except for its version number. Use it only if R1 doesn't help. The XDJ-RX refuses to install the version it already has, so R2 calls itself a higher version, and afterwards your XDJ-RX reports that number for good. A later R2 then needs a higher number again.

    2.22 for a unit that shows 2.21. One above what your XDJ-RX shows.

    Install

    1. Copy XDJRX.UPD from "Install" to the top level of an otherwise empty stick, formatted FAT32 with MBR (see above; FAT32 on GPT doesn't work).
    2. Switch the XDJ-RX off and plug the stick into the DECK 1 USB port.
    3. Hold DECK 1 USB STOP and DECK 1 RELOOP/EXIT and switch it on. Keep holding until the update screen appears.
    4. Wait for "{{NAME}} installed." Don't switch off while it's writing.
    5. Switch off, remove the stick, switch on. The new settings are in UTILITY.

    Safe start: a start that hangs, or that is switched off within its first minute, is followed by one start without the mod. So leave it on for a minute after switching on. The zip's README-FIRST.txt has the details, the error screens and how to report a bug.

    What this page does

    • It reads your two files in this browser tab. Nothing is uploaded: the page's security rule (connect-src 'none', in its source) forbids every network connection, and it works with Wi-Fi off.
    • It checks that they're exactly Pioneer's files, by checksum, and takes the update key from Pioneer's GPL package. The key stays in this tab's memory and is never shown or saved.
    • It adds the mod (one library and one changed start line) to Pioneer's app archive. The result is checked against the archive that was tested on real hardware, byte for byte, so it can't build anything else.
    • It builds the files the XDJ-RX's own update mode reads. Only the app area of the XDJ-RX is ever written: never the boot loader, the system or the update mode itself.
