# Changelog

## XDJRX-MOD 1.0 (2026-11-13)

First public release. For the XDJ-RX (first model) on Pioneer's firmware 2.21.

New in UTILITY:
- CUE MODE: NORMAL / SPLIT / SPLIT STEREO (PX5-style: master in stereo while nothing is cued).
- MASTER LEVEL DISPLAY: PRE / POST MASTER LEVEL.
- MASTER MONO, BOOTH MONO.
- DISPLAY REFRESH: 20 / 30 FPS.
- WAVEFORM COLOR: BLUE / RGB / 3-BAND, from rekordbox's colour waveform data.
- WAVEFORM SCROLL: ORIGINAL / SMOOTH.
- BEAT JUMP A / B (1 to 32 beats) on the pads, SHIFT + AUTO BEAT LOOP.
- JOG LIGHT: TOUCH / ON AIR.

Also:
- Safe start: after a hung start, or a switch-off within the first minute, the next start runs without the mod.
- Bug-report log, written only while a folder `xdjmod-capture` is on a stick.
- The web builder: builds the install, restore (R1) and emergency (R2) files in the browser, offline.
